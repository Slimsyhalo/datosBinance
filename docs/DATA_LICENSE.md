# Atribución y alcance de licencia de datos

Fuente: **Binance Vision**, https://data.binance.vision/.
Se conservan datos originales y sus checksums. Los CSV normalizados e indicadores son transformaciones documentadas.
Este proyecto es independiente; Binance no lo patrocina ni lo avala.

Términos consultados el 9 de octubre de 2026:
https://github.com/binance/binance-public-data/blob/master/TERMS_AND_CONDITIONS.md
(versión 1.0; actualización indicada: 26 de agosto de 2026).

El documento identifica **CC BY-NC-SA 4.0** para los datasets, salvo designación específica distinta,
y contempla investigación personal no productiva. Incluye restricciones adicionales sobre uso comercial,
ejecución propietaria en vivo, generación comercial automatizada de órdenes y distribución remunerada de señales.
Las transformaciones redistribuidas del dataset se atribuyen a Binance Vision y se mantienen bajo
CC BY-NC-SA 4.0: https://creativecommons.org/licenses/by-nc-sa/4.0/.

No usar el README MIT del código fuente de Binance como licencia de sus datos.
Esta atribución no concede derechos adicionales ni confirma que todos los usos posibles estén permitidos.
Revisar los términos completos antes de cambiar el uso o distribución de la investigación.

Macro: FRED/St. Louis Fed, BLS y Federal Reserve Board; cada serie conserva su fuente y
puede estar sujeta a derechos del proveedor original (por ejemplo VIX/CBOE).
No se atribuye la licencia de Binance a datos macro de terceros.
